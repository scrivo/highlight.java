highlight.java demo

highlight.java is a server-side syntax highlighter written in Java, a port of highlight.js. This demo is a Quarkus application that uses highlight.java as any application would: a single Highlighter is injected and serves all requests. The sample snippets of the {languageCount} languages come from the tests of highlight.js.

  • Auto-detection: the language of each snippet is detected by highlighting it with every language.
  • Comparison with highlight.js: each snippet highlighted by highlight.java next to the same snippet highlighted by highlight.js in your browser.
  • Line numbers: highlighted code split into lines with HighlightUtilities.splitCodeIntoArray().
  • Example: the simplest use of highlight.java.
