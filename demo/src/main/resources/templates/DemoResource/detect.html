highlight.java auto-detection

This page shows all languages supported by highlight.java, each snippet is highlighted in its own request (in an iframe) and its language is detected automatically. Most snippets do not contain working code :-).

Automatic detection happens in a brute force fashion, each snippet is highlighted in every language: loading this page causes {languages.size} × {languages.size} highlights. The requests run in parallel, served by a single Highlighter.
